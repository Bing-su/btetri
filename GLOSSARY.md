# btetri

Terms for the terminal game, its menu, and local results.

| Term      | Meaning                                                                                                |
| --------- | ------------------------------------------------------------------------------------------------------ |
| Game      | One play session, from its first piece until completion or top-out. Returning to the menu abandons it. |
| Mode      | The goal of a game: Marathon level progression, Sprint's 40 lines, or Ultra's two-minute score.        |
| Record    | A completed or topped-out game's result, including player, mode, score, levels, lines, and duration.   |
| Menu item | One main-menu choice: player, mode, starting level, start game, records, or quit.                      |
| Theme     | The terminal palette for the board, pieces, ghost, text, borders, and selected choices.                |
